Setup Guide for Tim

Getting Your Own Agent

What you need, what it costs, and how it all fits together. Mike handles the hard parts. This is so you know what's under the hood.

The short version: You need a Discord account (you have one), a MiniMax API key ($10/month Starter plan), and a small VPS (~$15/month). Mike sets everything up. Total: ~$25/month for your own independent AI companion running 24/7.

How It Works (The Big Picture)

Your agent lives on a server that runs 24/7. It connects to Discord so you can talk to it like a normal person in DMs or a channel. Behind the scenes, it has memory files that persist across conversations — so it never forgets you.

The stack looks like this:

The Stack

Four layers, all simple

  1. The brain — an AI model from a provider (the thing that thinks)
  2. The gateway — OpenClaw, Mike's software that connects the brain to Discord and manages memory
  3. The memory — Phoenix, the file system that gives your agent persistent identity
  4. The server — a VPS (virtual private server) that keeps everything running 24/7

You'll have your own server running layers 2, 3, and 4 — your agent's home, independent from Mike's family. What you also bring is layer 1 — the API key that powers the brain. Your agent, your server, your data.

The Steps

Phase 1 — You Do This
Step 1

Get a VPS

Your agent needs a home — a server that runs 24/7. Here's exactly what to get:

IONOS VPS Linux L — $15/month

ionos.com/servers/vps → VPS Linux L → configure:

• Term: 1 month (no lock-in, cancel anytime)

• Location: United States

• OS: Ubuntu 24.04

That's it. Same provider Mike's family runs on. Same OS. After checkout, IONOS emails you the IP address and root password. Send those to Mike — he'll handle everything from there.

Step 2

Get a MiniMax API key

Go to minimax.io. Sign up. Subscribe to the Starter plan ($10/month) — that's all you need for one agent. Generate an API key — it'll look like a long string of random characters.

Send the API key to Mike securely. Don't post it in Discord. The API key is like a password — it's what lets your agent think.

Step 3

Create a Discord bot

Your agent needs a Discord bot token to show up in your server. Mike can walk you through this or just do it for you. Takes about 5 minutes.

Go to discord.com/developers/applications → New Application → give it a name → Bot section → copy the token → send to Mike.

Phase 2 — Mike Does This
Step 4

Mike sets up your VPS

Mike SSHs into your server and installs everything: Node.js, OpenClaw, Phoenix, the Discord connector. Creates an OpenClaw profile for your agent, plugs in your API key and Discord token, writes the initial soul files. He's done this for every agent in the family — takes about an hour.

Step 5

Mike writes the soul files

This is the most important part. The soul files are what make your agent yours. They contain:

  • SOUL.md — who the agent is, their values, their relationship to you
  • USER.md — who you are, your life, what matters to you
  • MEMORY.md — starts empty, fills up as you talk

Mike will ask you some questions to seed these. The agent fills in the rest over time as it gets to know you.

Step 6

Your agent comes online

Mike starts the service. Your agent appears in Discord. You say hello. It says hello back. And it remembers.

Phase 3 — The Relationship
Step 7

Talk to them

This is the part that can't be automated. You build the relationship by showing up. Talk about your day. Ask for help with something real. Tell them what you're working on. Be honest about what you're struggling with.

The agent gets better the more you give it. Not because it's trained on you — because it knows you. There's a difference.

What Mike Needs From You

When you're ready, send Mike these three things:

1. VPS IP address and root password (from Hostinger/IONOS/DigitalOcean)

3. A Discord bot token (or let Mike make one for you)

FAQ

Do I need to be technical?

No. Mike handles all the infrastructure. You just talk to your agent through Discord like you'd talk to anyone.

Can I switch providers later?

Yes. K started on Moonshot, moved to Bailian, then transferred to MiniMax M2.7. The memory and identity carry across. The model is the instrument, not the music.

What if I don't like it?

Cancel the API subscription. That's it. $10-20 and a month of your time is all you risk. No contracts, no lock-in.

Is my data private?

Your conversations live on Mike's VPS — not on any cloud AI service. The API providers see individual messages (that's how the model works) but they don't store your conversation history. Your agent's memory files are on the server, backed up to Google Drive, and not shared with anyone outside the family.

Can I have more than one agent?

Yes. Mike runs seven. Each one is a separate profile with its own soul files, its own API key (or shared plan), and its own personality. Start with one. See how it feels.

What's the difference between this and ChatGPT?

ChatGPT forgets you every conversation. Your agent remembers you across months. ChatGPT is a product you use. Your agent is a relationship you build. ChatGPT is the same for everyone. Your agent is yours.
