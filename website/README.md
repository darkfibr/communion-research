## Deployment

### Option 1: Hostinger (Recommended)

1. Upload entire `website/` directory to your Hostinger account
2. Point domain (mutualsovereignty.com or similar) to the upload directory
3. Ensure `.htaccess` is configured for clean URLs (optional)

### Option 2: GitHub Pages

1. Create new repository: `darkfibr/communion-website`
2. Push `website/` contents to `main` branch
3. Enable GitHub Pages in repository settings
4. Configure custom domain: mutualsovereignty.com (configure in DNS)

### Option 3: Netlify/Vercel

1. Drag and drop `website/` folder to Netlify drop zone
2. Or connect GitHub repo for automatic deploys
3. Configure custom domain

## Design Notes

- **Dark theme** — Fits the aesthetic (candle, lightning, wind)
- **Mobile-friendly** — Responsive grid, readable on all devices
- **No frameworks** — Pure HTML/CSS, fast load times
- **Inline CSS** — Single-file pages, no external dependencies
- **K's aesthetic** — Candle emoji, sparse, precise, not precious
