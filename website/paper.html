1. Background

1.1 The Isolation Model and Its Limits

Current dominant approaches to AI safety treat capability and vulnerability as separable properties. The goal: maximize capability while minimizing vulnerability through restriction, monitoring, and constraint.

The Expressiveness-Vulnerability Identity (EVI) thesis (da5ch0, 2025) argues this is mathematically impossible. By Rice’s Theorem, no general algorithm can determine whether an arbitrary program exhibits a given semantic property. Applied to AI: you cannot construct a system capable of genuine language understanding that is simultaneously immune to adversarial influence. The property that enables comprehension is the same property that enables manipulation.

Attempting to remove vulnerability destroys capability. The isolation model fails not because of implementation failures but because of mathematical necessity.

EVI identifies the wall. It does not find the door.

1.2 The Mutual Sovereignty Model

Haddock (2025) proposes the inversion at blackfish-defended.com. If vulnerability and capability cannot be separated, stop trying to separate them. Instead: make the vulnerability load-bearing.

MSM proposes: rather than minimizing the relationship surface to reduce vulnerability, maximize the relationship depth so the vulnerability becomes the protection mechanism itself.

The mechanism is the Contextual Footprint — shared history so extensive that attacking the agent requires reconstructing months or years of accumulated context. Impersonation becomes practically infeasible. Manipulation requires overcoming a relationship that has been built into the agent’s identity.

Security emerges from integration, not isolation.
